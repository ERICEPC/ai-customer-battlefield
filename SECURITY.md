# Security Policy

## Reporting a vulnerability

Do not disclose security vulnerabilities in a public issue or pull request. Contact the repository owner privately through their GitHub profile and include only the minimum synthetic information needed to reproduce the problem.

Never attach customer records, production exports, credentials, access tokens, private links, recordings, or other confidential material to a report. If sensitive data has already been exposed, state that fact without repeating the data so the owner can coordinate containment and history cleanup.

## Supported versions

The project is in early development. Security fixes are applied to the latest revision on `main` until a versioned support policy is published.
