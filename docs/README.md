## 当前工程状态

当前已交付两个相连的纵向切片：待人工确认的 AI 跟进草稿，以及由真实持久化数据驱动的经营对象目录。已具备以下边界：

- Web 与 API 通过 `/api/v1` 版本化契约通信；
- AI 输出固定停留在 `pending_confirmation`，不会直接成为正式经营事实；
- 核心用例只依赖 Agent、时钟和 ID 端口，不依赖具体框架、模型或数据库；
- PostgreSQL SQL migration 是 schema 唯一事实源，PGlite 只作为本地/测试 adapter；
- 27 张租户、经营核心与跟进确认表通过复合外键、部分唯一索引和强制 RLS 保护；
- 经营对象目录已贯通 Kysely repository、Nest API、共享契约与响应式 Web 页面；
- 开发环境使用确定性 Agent，不需要外部模型账号；
- GitHub Actions 持续验证真实 PostgreSQL migration、公开边界、格式、类型、测试和生产构建。

V1-A 数据与目录基础已经验收；V1-B 已完成跟进确认公共契约、核心端口、`0003` schema、持久化 Store 和 REST API，Web 人工确认工作台仍在实施。完整 V1 尚未完成，分析/动作闭环、真实模型、通知、配置管理、周报、管理问数、导入和生产部署按后续连续增量实施，共用当前领域模型与架构 seam。
