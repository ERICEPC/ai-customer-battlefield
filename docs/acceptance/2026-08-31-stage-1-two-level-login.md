# 阶段 1 验收：销售与直属领导登录

## 本阶段交付

- 用真实账号、密码和服务端会话替代前端伪造身份；
- 首期只保留销售与直属领导两层身份；
- 销售账号显示所属部门和直属领导，不能进入管理问数；
- 直属领导显示所属部门和部门销售名单，可以进入管理问数；
- 管理问数同时受 Web 与 API 角色校验，销售手工输入地址或直接请求接口也不能绕过；
- 刷新页面保留登录，退出后受保护页面会回到登录页；
- 所有 Web 业务请求统一携带会话 Cookie，不再携带可由浏览器伪造的租户/用户请求头。

## 演示账号

| 身份 | 租户 | 邮箱 | 密码 |
|---|---|---|---|
| 销售1 | `alpha` | `sales1@demo.local` | `Demo@2026` |
| 领导A | `alpha` | `leader.a@demo.local` | `Demo@2026` |

这些账号只用于本地合成数据演示。

## 手动验收

启动 API 与 Web 后打开 `http://localhost:3000/login`。

### A. 销售1

1. 点击“销售1”演示账号，再点击“登录作战台”；
2. 应进入 `/workspace`，右上角显示“销售1 / 销售身份”；
3. 打开账号菜单，应看到“商业化一部”和直属领导“领导A”；
4. 左侧不应出现“管理问数”，工作台也不应出现“查看销售进展”；
5. 手工访问 `/ask`，应看到“当前身份不能使用管理问数”；
6. 刷新页面，应继续保持销售1登录状态；
7. 点击“退出登录”，应回到登录页；再次直接访问 `/workspace`，仍应回到登录页。

### B. 领导A

1. 点击“领导A”演示账号，再点击“登录作战台”；
2. 应进入 `/workspace`，右上角显示“领导A / 直属领导”；
3. 打开账号菜单，应看到“商业化一部”和团队成员“销售1”；
4. 左侧应出现“管理问数”，工作台应出现“查看销售进展”；
5. 进入 `/ask`，销售选择框应出现“销售1 · 管理观察范围”。

## 本阶段边界

本阶段只关闭双角色身份、组织关系和登录会话。SenseAudio Agent 自然语言录入、AI 拆解核对、正式入库、只读业务台账、作战地图自动更新和领导站内通知属于后续可见阶段，不在本阶段冒充完成。
